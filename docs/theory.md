# Постановка задачи

## Силы

Центробежная сила элемента массой `m` с центром масс на расстоянии `r` от оси:

```
F = m · r · ω²
```

Сила направлена вдоль радиус-вектора центра масс в плоскости YZ и раскладывается на
компоненты `Fx`, `Fy`. Для шатунной шейки к массе добавляется `rod_rotating_mass` —
вращающаяся часть приведённой массы шатуна (поступательная часть `m1` относится к
поршневому пальцу и сюда не входит).

Группы сил:

- `F1` — щёки;
- `F2` — шатунные шейки (с учётом массы шатуна);
- `F3 = s · ω²` — противовесы, коэффициенты `s_i` подбираются оптимизацией.

## Метод сечений

Координата `z` отсчитывается от **правого** конца вала. Момент в сечении:

```
M(z) = Σ H(z − L_i) · F_i,     H(d) = d при d > 0, иначе 0
```

где `L_i` — расстояние от правого конца до точки приложения силы `F_i`.
Силы в мм·Н дают момент в Н·мм; `NMM_TO_NM = 1e-3` переводит в Н·м.

## Подбор противовесов

`M(z)` линеен по `s`, поэтому `max|M(z)|` выпукла по `s`, и задача — линейная программа:

```
min  t
при  −t ≤ M(z_k) ≤ t         для всех сечений z_k
     Σ F1 + Σ F2 + Σ F3 = 0   (баланс сил)
     M(z_end) = 0             (нулевой момент на конце вала)
```

Решается HiGHS (`scipy.optimize.linprog`). Коэффициент можно зафиксировать на нуле
значением `"F"` в `make_initial_coefficients`, либо ограничить через `s_bounds`.

## Длина вала

Длина получается последовательным суммированием ширин в порядке следования
элементов вдоль вала (x-координаты центров масс используются только для порядка):

- вал начинается с половины коренной шейки;
- щека добавляет `cheek_width`, шатунная шейка — `crankpin_journal_width`;
- две щеки подряд без шатунной шейки между ними означают опорную коренную шейку:
  добавляется `main_journal_width`;
- вал заканчивается половиной коренной шейки.

## Проверка глобальности оптимума

1. **Двойственность.** Строится и решается двойственная ЛП; по теореме сильной
   двойственности совпадение оптимумов доказывает глобальность (`verify_optimum_via_duality`).
2. **ККТ.** Проверяются допустимость, стационарность и дополняющая нежёсткость по
   множителям Лагранжа HiGHS (`verify_kkt_conditions`).
3. **Чувствительность.** Вариация одного `s_i` при остальных на оптимуме показывает
   выпуклую «чашу» с минимумом в найденной точке (`sweep_sensitivity`, `plot_sensitivity`).
