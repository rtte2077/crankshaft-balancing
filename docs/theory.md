# Постановка задачи

## Силы

Центробежная сила элемента массой `m` с центром масс на расстоянии `r` от оси:

```
F = m · r · ω²
```

Сила направлена вдоль радиус-вектора центра масс в плоскости YZ и раскладывается на
компоненты `Fx`, `Fy`. Для шатунной шейки к массе добавляется `rod_rotating_mass` —
вращающаяся часть приведённой массы шатуна (поступательная часть `m1` относится к
поршневому пальцу и сюда не входит).

Группы сил:

- `F1` — щёки;
- `F2` — шатунные шейки (с учётом массы шатуна);
- `F3 = s · ω²` — противовесы, коэффициенты `s_i` подбираются оптимизацией.

## Метод сечений

Координата `z` отсчитывается от **правого** конца вала. Момент в сечении:

```
M(z) = Σ H(z − L_i) · F_i,     H(d) = d при d > 0, иначе 0
```

где `L_i` — расстояние от правого конца до точки приложения силы `F_i`.
Силы в мм·Н дают момент в Н·мм; `NMM_TO_NM = 1e-3` переводит в Н·м.

## Подбор противовесов

`M(z)` линеен по `s`, поэтому `max|M(z)|` выпукла по `s`, и задача — линейная программа:

```
min  t
при  −t ≤ M(z_k) ≤ t         для всех сечений z_k
     Σ F1 + Σ F2 + Σ F3 = 0   (баланс сил)
     M(z_end) = 0             (суммарный внешний момент равен нулю)
```

Решается HiGHS (`scipy.optimize.linprog`). Коэффициент можно зафиксировать на нуле
значением `"F"` в `make_initial_coefficients`, либо ограничить через `s_bounds`.

## Выбор среди равноценных решений: наименьший размах

Оптимум $\min t$ обычно неединственный. Из множества решений с $\max|M| = M_{opt}$
выбирается решение с наименьшим размахом эпюры $R = \max_k M(z_k) - \min_k M(z_k)$:

$$\min\ (hi - lo) \quad \text{при} \quad lo \le M(z_k) \le hi,\ \ -t \le M(z_k) \le t,\ \
t \le M_{opt}(1+\varepsilon),\ \ \text{два равенства}.$$

Задача линейна; $hi$, $lo$ масштабируются так же, как $t$ ($hi' = hi/\omega^2$). Так как
$M(0) = 0$, всегда $lo \le 0 \le hi$ и $R \ge \max|M|$; у минимаксного решения эпюра
обычно касается и $+M_{opt}$, и $-M_{opt}$ (чебышёвское альтернирование), и тогда
$R = 2M_{opt}$ у всех оптимальных решений — выбор ничего не меняет. Если же часть
противовесов упирается в `bounds`, оптимальные решения различаются размахом, и выбор
его уменьшает.

**Сокращение строк.** $M(z)$ — ломаная с изломами только в точках приложения сил
$L_1, L_2, L_3$. На отрезке между соседними точками $M$ линейна, поэтому максимум и
минимум $M$ по узлам сетки, попавшим на этот отрезок, достигаются в крайних из них.
Ограничения $|M(z_k)| \le t$ и $lo \le M(z_k) \le hi$ достаточно ставить в первом и
последнем узлах сетки и в узлах, ближайших слева и справа к каждой точке приложения
силы: в остальных узлах они следуют из линейности. Это та же ЛП (то же допустимое
множество), но с ~50 строками вместо $2 n_z$.

## Две группы статических моментов

Бюджет оси — суммарный статический момент $B(s) = \sum_i |s_i|$ (`norm="l1"`) или
$\max_i |s_i|$ (`norm="linf"`). Свободные коэффициенты $s_j$, зафиксированные — константы
$\bar s_i$; их вклад $B_c = \sum |\bar s_i|$ (или $\max |\bar s_i|$) в бюджет постоянен.

**Линеаризация модуля.** Для `l1` вводятся $u_j \ge 0$ с

$$u_j \ge s_j, \qquad u_j \ge -s_j,$$

так что $u_j \ge |s_j|$, и $\sum_j u_j + B_c \le B$ — линейное ограничение. В любой точке
минимума $\sum u_j$ выполняется $u_j = |s_j|$ (иначе $u_j$ можно уменьшить). Для `linf`
вводится одна переменная $u \ge \pm s_j$ для всех $j$ и ограничение $u \le B$
($B \ge B_{\min} \ge \max|\bar s_i|$, так что константа учитывается автоматически).

Переменные ЛП: $[s, u, t]$. Обозначим $\mathcal{E}$ — два равенства (баланс сил и
$M(z_{end}) = 0$) вместе с `bounds`.

1. $B_{\min} = \min \{\sum u_j + B_c : \mathcal{E},\ u \ge |s|\}$; строки
   $-t \le M(z_k) \le t$ не включаются. Решение — $s^{(1)}$ (группа 1).
2. $M_{opt} = \min \{t : -t \le M(z_k) \le t,\ \mathcal{E}\}$ — исходная задача.
3. $B_{\max} = \min \{\sum u_j + B_c : \mathcal{E},\ u \ge |s|,\
   -t \le M(z_k) \le t,\ t \le M_{opt} + \varepsilon\max(M_{opt}, 1),\
   hi - lo \le R_{opt}(1+\varepsilon)\}$, где $R_{opt}$ — наименьший размах при
   $\max|M| = M_{opt}$ (см. выше).
   Допустимое множество шага 3 содержится в допустимом множестве шага 1, поэтому
   $B_{\max} \ge B_{\min}$.
4. $T(B) = \min \{t : -t \le M(z_k) \le t,\ \mathcal{E},\ u \ge |s|,\ \sum u_j + B_c \le B\}$
   при $B = B(p) = B_{\min} + \tfrac{p}{100}(B_{\max} - B_{\min})$ (на практике с
   допуском $B(p)(1+\varepsilon)$ на погрешность решателя).

**Монотонность.** Если $B' \ge B$, то допустимое множество задачи 4 при $B$ содержится
в множестве при $B'$, значит $T(B') \le T(B)$: $\max|M|$ не возрастает по $p$.

**Крайние значения.** При $p = 0$ бюджет равен $B_{\min}$: допустимы ровно конфигурации
с минимальной суммой $|s|$, и среди них выбирается лучшая по моменту — детерминированный
выбор при неединственности. При $p = 100$ бюджет $B_{\max}$ допускает решение шага 3,
так что $T(B_{\max}) = M_{opt}$ — исходный результат.

**Линейность бюджета по $p$.** $T(B)$ — оптимальное значение ЛП как функция правой
части, поэтому она выпуклая кусочно-линейная и невозрастающая. На $[B_{\min}, B_{\max}]$
она строго убывает: если бы $T$ была постоянной на отрезке $[B_1, B_2]$ с
$B_2 < B_{\max}$, то по выпуклости она не убывала бы и правее, и тогда
$T(B_2) = T(B_{\max}) = M_{opt}$, то есть $B_{\max} \le B_2$ — противоречие. Отсюда
бюджетное ограничение в шаге 4 активно: если бы итоговое $s$ имело
$B(s) < B(p)$, то $T(B(s)) = T(B(p))$, что противоречит строгому убыванию. Поэтому
$B(s) = B(p)$, и суммарный статический момент растёт линейно по $p$.

**Независимость осей.** Задачи по осям x и y решаются отдельно, поэтому
минимизируются $\sum|s_x|$ и $\sum|s_y|$ по отдельности. Сумма модулей векторов
$\sum_i \sqrt{s_{x,i}^2 + s_{y,i}^2}$ связала бы оси и сделала задачу конической
(SOCP), а не ЛП.

**Группы.** $s^{(2)} = s - s^{(1)}$ — разложение для отчёта; физически на щеке один
противовес с итоговым $s$.

**Проверка оптимальности.** Задача шага 4 — обычная ЛП в форме
$\min c^\top x,\ A_{ub}x \le b_{ub},\ A_{eq}x = b_{eq}$ с границами переменных; её
матрицы хранятся в `result["lp"]`, поэтому двойственный сертификат и условия ККТ
(ниже) применяются к ней без изменений.

## Длина вала

Длина получается последовательным суммированием ширин в порядке следования
элементов вдоль вала (x-координаты центров масс используются только для порядка):

- вал начинается с половины коренной шейки;
- щека добавляет `cheek_width`, шатунная шейка — `crankpin_journal_width`;
- две щеки подряд без шатунной шейки между ними означают опорную коренную шейку:
  добавляется `main_journal_width`;
- вал заканчивается половиной коренной шейки.

Эти ширины — значения по умолчанию. Если у элемента задан `width`, вместо
`cheek_width`/`crankpin_journal_width` берётся он; ширину отдельной коренной шейки
с номером $k$ (слева направо с 0, концевые — первая и последняя) задаёт
`engine.main_journal_widths[k]`.

## Проверка глобальности оптимума

1. **Двойственность.** Строится и решается двойственная ЛП; по теореме сильной
   двойственности совпадение оптимумов доказывает глобальность (`verify_optimum_via_duality`).
2. **ККТ.** Проверяются допустимость, стационарность и дополняющая нежёсткость по
   множителям Лагранжа HiGHS (`verify_kkt_conditions`).
3. **Чувствительность.** Вариация одного `s_i` при остальных на оптимуме показывает
   выпуклую «чашу» с минимумом в найденной точке (`sweep_sensitivity`, `plot_sensitivity`).
